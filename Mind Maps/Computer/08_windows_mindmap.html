Starting the Computer — Booting
  • Booting = process of loading or reloading the operating system into computer memory.
  • Cold Boot: OS loads when power is turned on.
  • Warm Boot: OS reloads when the computer is already on.

Cold Boot

Power OFF → Power ON → OS loads

Warm Boot

Computer already ON → OS reloads/restarts
Tasks Performed at Boot-up
1. POSTPower-On Self Test checks devices
2. InitializeCPU registers, device controllers, main memory
3. Bootstrap LoaderSpecial program locates/loads OS
4. AuthenticationUser name + Password
5. User InterfaceInteraction with programs begins
  • Hardware itself does not know where the OS resides or how to load it; the source names the special program Bootstrap loader.
  • Authentication/login occurs through user name and password.
⚡ QUICK RECALL
POST → Initialize → Bootstrap Loader → Login → User Interface.

Microsoft Windows Accessories / Utilities

Magnifier

Display utility that enlarges a portion of the screen for better readability.

On-Screen Keyboard

Visual keyboard with standard keys; keys can be selected using mouse/pointing device.

Disk Clean-up

Deletes temporary Internet/program files, empties Recycle Bin and removes temporary files.

Resource Monitor

Shows CPU, disk, network and memory usage; also per-process statistics.

Task Scheduler

View/customize scheduled tasks and create custom scheduled tasks.

Disk Defragmenter

Consolidates fragmented data on a volume so it can operate more efficiently.
More Windows Tools

System Information

Shows details about the computer, peripherals, environment variables and startup programs.

Character Map

Used to copy/paste accented and foreign-language characters into Windows applications.

System Restore

Recovery tool that reverses certain kinds of operating-system changes.
Data Fragmentation
The source describes fragmentation as a particular piece of data being split into several pieces and saved on the hard disk.
