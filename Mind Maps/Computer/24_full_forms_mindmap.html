High-Yield Computer & Hardware
CPU — Central Processing Unit • ALU — Arithmetic Logic Unit • RAM — Random Access Memory • ROM — Read Only Memory • BIOS — Basic Input Output System • HDD — Hard Disk Drive • SSD — Solid State Drive • SMPS — Switch Mode Power Supply • PSU — Power Supply Unit • POST — Power On Self Test.
High-Yield Networking & Internet
LAN — Local Area Network • MAN — Metropolitan Area Network • WAN — Wide Area Network • PAN — Personal Area Network • TCP — Transmission Control Protocol • IP — Internet Protocol • DNS — Domain Name System • HTTP — Hyper Text Transfer Protocol • HTTPS — Hyper Text Transfer Protocol Secure • FTP — File Transfer Protocol • URL — Uniform Resource Locator • VPN — Virtual Private Network.
High-Yield Web / Software / Database
HTML — Hyper Text Markup Language • CSS — Cascading Style Sheets • SQL — Structured Query Language • DBMS — Data Base Management System • RDBMS — Relational Data Base Management System • OOP — Object Oriented Programming • GUI — Graphical User Interface • CUI — Character User Interface.
High-Confusion Terms Both retained VGA entries now use Video Graphics Array. MB = Megabyte in storage units; motherboard is a context-specific abbreviation. HPC is given as “Handheld Personal Computer/High Performance Computer.” PDU is given as “Protocol Data Unit / Power Distribution Unit.” SAM is given as “Software Asset Management/Sequential Access Method.” ISO is the official short name of the International Organization for Standardization.
